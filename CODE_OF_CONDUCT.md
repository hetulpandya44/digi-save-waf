# Code of Conduct

## Our Standard

We want Digi Save WAF to be a respectful, constructive, and technically helpful project space.

Examples of positive behavior:

- giving actionable and respectful feedback
- being welcoming to learners and contributors
- focusing on technical improvement instead of personal criticism
- sharing security ideas responsibly

Examples of unacceptable behavior:

- harassment or personal attacks
- publishing private exploit details irresponsibly
- abusive or discriminatory language
- intentionally disruptive behavior

## Enforcement

Project maintainers may remove, edit, or reject contributions and discussions that violate this code of conduct.
