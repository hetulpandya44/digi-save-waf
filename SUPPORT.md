# Support

## Getting Help

If you are exploring Digi Save WAF:

- read the [README](README.md)
- review the [Setup Guide](docs/SETUP.md)
- use the [Demo Guide](docs/DEMO.md)
- check the [Results](docs/RESULTS.md) and [Architecture](docs/ARCHITECTURE.md)

## Good Issue Topics

- reproducible bugs
- documentation improvements
- detection false positives or false negatives
- UI or developer-experience improvements

## Before Opening an Issue

- make sure the problem is reproducible
- include your OS and Python version
- include the exact request or steps if the issue is about detection
