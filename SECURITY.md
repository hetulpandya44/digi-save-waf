# Security Policy

## Supported Use

This repository is primarily maintained as an academic and portfolio project. It is suitable for local testing, classroom demonstrations, and controlled lab usage.

## Reporting a Vulnerability

If you believe you found a genuine vulnerability in the defensive code:

1. Do not open a public issue with exploit details.
2. Report it privately through GitHub or email the maintainer directly.
3. Include:
   - affected file or area
   - reproduction steps
   - expected vs actual behavior
   - impact assessment

## Demo Target Warning

The `demo_target` application is intentionally vulnerable and exists only for safe local demonstrations and authorized testing. It must not be deployed publicly.
